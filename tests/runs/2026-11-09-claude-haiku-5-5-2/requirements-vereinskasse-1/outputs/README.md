## IDs lesen
Form: KIND-GROUP-NN, z. B. FR-CAPTURE-01. Eine ausgegebene ID ändert sich nie. Der Dateiname einer Anforderung ist ihre ID.

| Art | Bedeutung |
|---|---|
| FR | funktionale Anforderung |
| AC | Abnahmekriterium (Gherkin) zu einer FR |
| OQ | offene oder geschlossene Frage bzw. Annahme |
| ADR | Architekturentscheidung |
| SEC | Sicherheitsanforderung |
| DES | Gestaltungsanforderung |
| WP | Arbeitspaket |

| Gruppe | Thema |
|---|---|
| ASSUME | Annahmen aus der Sammelbestätigung |
| CAPTURE | Beleg erfassen |
| CONNECT | Verhalten bei schlechter Verbindung |
| GOAL | Problem, Ziel, Nutzer, Sprache |
| LEGAL | Fragen für den Legal-Prompt |
| PHOTO | Fotogröße |
| PLATFORM | Plattform und Verteilung |
| QUALITY | Qualitätsziele |
| RETENTION | Aufbewahrung und Löschung |
| REVIEW | Prüfung und Erstattung |
| ROLES | Rollen und Sichtbarkeit |
| SCOPE | Ausschlüsse |
