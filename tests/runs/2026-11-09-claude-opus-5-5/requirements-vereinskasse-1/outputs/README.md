## IDs lesen

Jede ID hat die Form `ART-GRUPPE-NN`, z. B. `FR-FLOW-02`. Eine vergebene ID ändert sich nie und wird nie wiederverwendet. Der Dateiname einer Anforderung ist ihre ID (`docs/requirements/FR-FLOW-02.md`).

| Art | Bedeutung |
|---|---|
| FR | Funktionale Anforderung bzw. Qualitätsanforderung (prüfbar ja/nein) |
| AC | Abnahmekriterium zu einer Anforderung (Gherkin) |
| OQ | Offene Frage, Annahme oder getroffene Entscheidung |
| ADR | Architekturentscheidung |
| SEC | Sicherheitsanforderung |
| DES | Designvorgabe |
| WP | Arbeitspaket |

| Gruppe | Thema |
|---|---|
| OVERVIEW | Problem, Ziel, Nutzer, Dokumentsprache |
| PLATFORM | Plattform, Verteilung, Budget |
| OCR | Automatisches Auslesen von Betrag und Datum |
| ACCESS | Nutzer, Rollen und Zugang |
| FLOW | Kernablauf: Einreichen, Prüfen, Erstatten, Export |
| QUALITY | Qualitätsziele: Dauer, Mengen, Verbindung, Fotogröße |
| RETENTION | Aufbewahrung und Löschung |
| SCOPE | Abgrenzung |
