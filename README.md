# AI Prompt Library

**Version:** PL-WEB-4.0 · **Stand:** 15.10.2026 · **Prüfstatus:** nach der
Entkopplung erneut praktisch zu prüfen.

Wiederverwendbare Prompts für die KI-gestützte Entwicklung von Websites,
Webanwendungen und PWAs. Die Sammlung bietet einzeln nutzbare Prompt-Snippets
für Anforderungen, Design, Architektur, Sicherheit, Review und Arbeitsplanung.
Du wählst die Aufgabe, die dein Projekt gerade braucht. Die Anleitung beschreibt
einen sinnvollen Ablauf; vorhandene Ergebnisse können direkt weiterverwendet
und unpassende Aufgaben ausgelassen werden. Jeder Prompt erzeugt sein eigenes
Artefakt und nutzt relevante, bereits vorhandene Projektdateien als Grundlage.

Der Coding-Agent übernimmt Recherche, Dokumentation und delegierte
Entscheidungen. Notwendige Nutzerentscheidungen werden mit verständlichen
Vorschlägen vorbereitet, damit möglichst wenig Texteingabe nötig ist.
Die Prompts bleiben so knapp wie möglich: Jede Regel muss zum Ergebnis beitragen.
Gemeinsame Qualitäts- und Sicherheitsvorgaben sorgen für konsistente Ergebnisse.
Die Library ist auch für lokale Projekte ohne Git oder Hostingdienst nutzbar.

Die Prompts stehen im Ordner **lib**. Jede Datei enthält eine kurze Anleitung
und einen vollständig kopierbaren Prompt für eine gemeinsame oder neue Session.
Die Vorlagen erstellen Spezifikationen und Pläne. Setup und Codeumsetzung
beginnen erst mit einem gesonderten Umsetzungsauftrag.
