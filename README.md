# AI Prompt Library

**Version:** PL-WEB-4.0 · **Stand:** 14.10.2026 · **Prüfstatus:** bedingt bestanden;
abschließende Funktionsprüfung in ScannerPWA ausstehend.

Wiederverwendbare Prompts für die KI-gestützte Entwicklung von Websites,
Webanwendungen und PWAs. Zehn aufeinander aufbauende Prompts helfen, eine Idee
in klare Anforderungen und eine umsetzbare Entwicklungsgrundlage zu überführen.

Der Coding-Agent übernimmt Recherche, Dokumentation und delegierte
Entscheidungen. Notwendige Nutzerentscheidungen werden mit verständlichen
Vorschlägen vorbereitet, damit möglichst wenig Texteingabe nötig ist.
Gemeinsame Qualitäts- und Sicherheitsvorgaben sorgen für konsistente Ergebnisse.

Die Prompts stehen im Ordner **lib**. Sie werden nacheinander in einer gemeinsamen
oder in getrennten Sessions verwendet. Jede Datei enthält eine kurze Anleitung
und einen vollständig kopierbaren Prompt.
