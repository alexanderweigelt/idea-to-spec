# AI Prompt Library

**Version:** PL-WEB-5.0 · **Stand:** 15.10.2026 · **Prüfstatus:** gekürzte
Fassung, praktisch noch nicht geprüft.

Wiederverwendbare Prompts für Spec-Driven Development von Websites,
Webanwendungen und PWAs: von der Projektidee über eine konsistente Spezifikation
bis zu Arbeitspaketen mit geplanten Prüfungen. Jeder Prompt ist ein eigenständiges
Skript, das eine eigene Ergebnisdatei erzeugt und vorhandene Dateien weiterverwendet.
Die Prompts erstellen nur Spezifikationen und Pläne; die Umsetzung braucht einen
eigenen Auftrag. Git und Hostingdienste sind optional.
